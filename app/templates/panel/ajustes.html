Tu página de reservas

Abrir

Compártela en Instagram, WhatsApp o Google. Para ponerla dentro de una página de WordPress, agrega un bloque HTML personalizado con esto:

<iframe id="reservared" src="{{ url_reservar }}?embed=1"
  style="width:100%;border:0;min-height:640px" title="Reservar hora"></iframe>
<script>
window.addEventListener("message", function (e) {
  if (e.data && e.data.reservaredAlto)
    document.getElementById("reservared").style.height = e.data.reservaredAlto + "px";
});
</script>
